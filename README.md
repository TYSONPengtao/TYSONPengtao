## 🚧 Current Main Project

### [TAO Digital Twin](https://github.com/TYSONPengtao/Tao-Digital-Twin)

A modular digital twin platform for connecting Web / Three.js and future Unreal Engine scenes with realtime data, environmental simulation and real physical devices.

Current work includes:

- Interactive 3D demo house
- 8 simulated smart-home devices
- React + TypeScript + React Three Fiber
- FastAPI backend
- REST + WebSocket communication
- Canonical device ↔ scene-node mapping
- Room temperature / humidity / air-speed state
- PET thermal-comfort analysis
- Solar-position analysis
- Reduced-order ventilation simulation
- Future Home Assistant / MQTT / ESP32 integration

```text
Web / Three.js       Unreal Engine / VR / AR
       \                    /
        \                  /
         +---- TAO Core ---+
               |
      Device / State / Command / Event
               |
     +---------+---------+---------+
     |         |         |         |
Home Assistant MQTT    Modbus    OPC UA
     |         |         |         |
 Smart Home   ESP32    PLC/IO   Industrial
```

## 🌡️ Digital Twin Research Direction

Current environmental-analysis path:

```text
Physical / Simulated Devices
            ↓
        Device State
            ↓
     Room Environment
            ↓
Temperature / RH / Air Speed / MRT
            ↓
       PET Comfort
            ↓
      3D Digital Twin
```

Next milestones:

1. Stabilize room-level environmental state
2. Add windows and doors as airflow openings
3. Build pressure / opening based ventilation
4. Add real weather and solar irradiance input
5. Add room heat-balance simulation
6. Evaluate EnergyPlus / CFD integration
7. Connect Home Assistant / MQTT / ESP32
8. Expand toward Unreal Engine and agricultural digital twins

## 🧭 What I Care About

- Build the **framework before feature overload**
- Keep visualization independent from hardware protocols
- Separate simulated, requested and confirmed physical state
- Prefer local-first systems where practical
- Treat safety as part of architecture, not an afterthought
- Turn experiments into reusable tools and documented systems
